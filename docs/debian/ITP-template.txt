  Description     : Lossless MP3 volume adjustment tool written in Rust

mp3rgain is a modern, memory-safe audio volume normalizer written in Rust.
It adjusts MP3 volume without re-encoding by modifying the global_gain
field in each frame's side information, preserving audio quality while
achieving permanent volume changes.

Features:
 - Lossless and reversible volume adjustment
 - ReplayGain track and album analysis
 - Support for MP3, AAC/M4A, OGG Vorbis, and FLAC formats
 - Full command-line compatibility with the original mp3gain
 - Memory-safe implementation in Rust
 - GUI version available (mp3rgui)

mp3rgain is an independent project, not a fork or successor of mp3gain.
While it provides a compatible CLI interface, it is a complete rewrite
with its own codebase and development goals.

Packaging Notes:

This package is published on crates.io (https://crates.io/crates/mp3rgain)
and can be built using debcargo. Pre-built .deb packages (amd64 + arm64)
are available from GitHub releases for testing.

A GUI companion package (mp3rgui) is also available and will be packaged
separately.

I intend to maintain this package with the Debian Rust Team. If you are
interested in co-maintaining or sponsoring, please contact me.
